# BMW X5 G05 з Кореї

Статичний сайт із шортлистом вживаних **BMW X5 (G05) xDrive30d M Sport**, які підбираються на
[Encar](https://fem.encar.com/) для пригону в Україну. Для кожного авто порахована ціна **«під ключ» у Києві**
(разом із розмитненням, доставкою та обліком) і показана комплектація за фабричним білд-листом BMW за VIN.

**Сайт:** https://volodymyr-babak.github.io/bmw-from-korea/

## Що на сайті

- `index.html` — список кандидатів: ціна під ключ, запас до стелі бюджету, пробіг, VIN, рядок ключових опцій.
  Є фільтри за роком, пробігом і ціною та сортування.
- `car.html?id=<listingId>` — сторінка одного авто: розклад платежів під ключ, кольори BMW з кодами,
  історія за корейським реєстром і **повна комплектація за VIN** з українськими назвами SA-кодів.

## Структура

```
index.html              головна
car.html                сторінка авто (?id=<listingId>)
assets/css/site.css     стилі, світла й темна теми через CSS-змінні
assets/js/common.js     формула розмитнення, форматери чисел, ключові опції, тема
assets/js/options.js    глосарій SA-кодів BMW: українські назви + групування
assets/js/index.js      головна: фільтри, сортування, рендер списку
assets/js/car.js        сторінка авто
data/cars.json          індекс: meta + масив авто (summary для головної)
data/cars/<id>.json     деталь авто: VIN, кольори, keyFeatures, повний список опцій
tools/sync_index.py     підтягує в індекс дані з детальних файлів
```

Дані лежать у JSON і не дублюються в розмітці — сторінки читають їх через `fetch`.

## Як додати щойно декодоване авто

1. Створити `data/cars/<listingId>.json` за зразком наявних: `vin`, `exterior`/`interior`
   (`name`, `german`, `code`), `keyFeatures`, `options` (усі S-коди з білд-листа mdecoder).
2. Запустити `python3 tools/sync_index.py` — скрипт перенесе VIN, кольори та `keyFeatures`
   в `data/cars.json`, виставить `decoded: true` і перерахує `meta.decodedCount`.
3. Якщо в білд-листі трапився новий S-код, додати його переклад у `assets/js/options.js`.
   Без перекладу код усе одно показується — але в групі «Інше» й англійською.

## Локальний запуск

Сторінки використовують ES-модулі й `fetch`, тому їх треба відкривати через сервер, а не з `file://`:

```bash
python3 -m http.server 8000
# http://127.0.0.1:8000/
```

## Формула ціни під ключ

Мита рахуються від **фіксованої мінімальної митної вартості P за роком виготовлення**, а не від корейської ціни:

| Рік | P (USD) |
|-----|---------|
| 2019 | 25 000 |
| 2020 | 36 000 |
| 2021 | 40 500 |
| 2022 | 43 000 |

```
мито   = 0,10 × P
акциз  = 75 €/л × 3,0 л × вік × 1,1648        вік = 2025 − рік
ПДВ    = 0,20 × (P + мито + акциз)
облік  = 0,05 × P + $124                       сертифікація $79 + реєстрація $45
під ключ = ціна авто + мито + акциз + ПДВ + облік + доставка $3700 + послуги $1000
```

Реалізація — `breakdown()` в `assets/js/common.js`. Вартість самого авто на сторінці виводиться
як залишок від ціни під ключ, тому розклад завжди сходиться в підсумок.
