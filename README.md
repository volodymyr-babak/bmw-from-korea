# Ford Ranger Wildtrak з Кореї

Статичний сайт із шортлистом вживаних **Ford Ranger Wildtrak** (2.0 дизель, виготовлення **2022+**),
які підбираються на [Encar](https://fem.encar.com/) для пригону в Україну. Для кожного авто —
**ціна в Кореї** (рівно та, що в оголошенні, у 만원, з довідковим доларовим еквівалентом за курсом
1372 ₩/$), пробіг, кількість різних ДТП, виплати за ремонт, зміни власника, фото й державний
звіт про стан.

Комплектація за VIN тут не декодується — за рішенням від 2026-09-24 у списку лише
рік, пробіг, ціна, ДТП, власники й ремонт.

**Сайт:** https://volodymyr-babak.github.io/bmw-from-korea/

> Історія: до вересня 2026 репозиторій вів добірку BMW X5 (G05) / X6 (G06) — звідси назва.
> Те авто куплене, і список повністю замінено на Ranger. Старі дані, декодери VIN і
> нотатки — в історії git до коміту, що зробив заміну.

## Що на сайті

- `index.html` — одна таблиця: ціна в Кореї, пробіг, різних ДТП, виплати за ремонт, зміни власника,
  VIN і позначки зі звіту інспекції. Сортування — клік по заголовку; фільтри за поколінням,
  роком, кількістю ДТП і наявністю ремонту.
- `car.html?id=<listingId>` — сторінка одного авто: галерея фото з оголошення, історія
  з корейського реєстру (розклад ДТП по датах), звіт інспекції (які панелі міняли чи варили,
  прокатна історія) і сирий текст оголошення.

## Структура

```
index.html              головна
car.html                сторінка авто (?id=<listingId>)
assets/css/site.css     стилі, світла й темна теми через CSS-змінні
assets/js/common.js     форматери чисел (만원 → $ за курсом), тема
assets/js/index.js      головна: фільтри, сортування, рендер таблиці
assets/js/car.js        сторінка авто
data/cars.json          індекс: meta + масив авто (summary для головної)
data/cars/<id>.json     деталь авто: фото, історія, звіт інспекції, текст оголошення
data/watch-state.json   стан доглядача: відсіяні лоти з причиною
tools/encar.py          клієнт Encar API (пошук, деталь, історія, інспекція)
tools/inspection.py     нормалізація державного звіту про стан
tools/watch.py          доглядач: продані / нові / зміна ціни → коміт і пуш
tools/sync_index.py     підтягує в індекс дані з детальних файлів
```

## Оновлення

```
python3 tools/watch.py --dry-run      # показати, що змінилось, нічого не писати
python3 tools/watch.py --no-publish   # записати дані без коміту
python3 tools/watch.py                # записати, закомітити, запушити
bash tools/install-watch-cron.sh      # щогодинний запуск із cron
```

Push у `data/last-change.md` запускає `.github/workflows/notify.yml`, який створює issue
з міткою `encar-watch` — так приходить лист про зміни. Локально дивитись через
`python3 -m http.server` (ES-модулі не працюють з `file://`).
